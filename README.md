# Анализ данных Яндекс Афиши

Проект по анализу поведения пользователей билетного сервиса Яндекс Афиша.

## Что сделано

- Предобработка данных: приведение выручки к рублям (конвертация тенге), 
  обработка аномалий, фильтрация выбросов по 99-му перцентилю.
- Профиль пользователя: даты заказов, атрибуты первого заказа, число 
  заказов, средняя выручка, среднее число билетов, интервал между покупками.
- Сегментный анализ: распределение по числу заказов, по типам мероприятий, 
  регионам, билетным операторам.
- Проверка гипотез: влияние типа мероприятия и размера региона на возврат.
- Корреляционный анализ: phi_k между признаками профиля и числом заказов.

## Ключевые выводы<br>

На что обратить внимание:<br>
1 Сегмент '2–3 билета'—ключевая аудитория (45% пользователей, 73.6% возврата). Рекомендуется включить персональные подборки, программа лояльности.<br>
2. Регулярность=лояльность. Если интервал>14 дней—триггерные письма и push.<br>
3. Триггерные кампании для спящих».Промокод на 2-ю покупку для однократных пользователей (38.7% выборки).<br>
4. Десктопный трафик— более лояльный. Не отказываться от канала.<br>
5. Жанры "театр" и "выставки"—точки входа лояльной аудитории. Рекомендуется развивать абонементы и подписки.<br>
6. Сегмент "5+ билетов" (18.8% возврата)—вероятно, B2B-организаторы. Требует отдельного исследования.<br>
<br>
Что НЕ делать:<br>

Не сегментировать по размеру региона—связи нет.<br>
Не фокусироваться только на мобильном или только на десктопе.<br>
Не ожидать лояльности от спорта и ёлок—разовые события.<br>
